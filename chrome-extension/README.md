# Chrome Extension (Optional - For Power Users)

**OPTIONAL ENHANCEMENT** - The web app works without this!

## Overview
Optional browser extension for advanced users who need enhanced features beyond what the web app provides.

## Why Optional?
Our web app handles 95% of use cases without requiring an extension. Install this only if you need:
- System audio capture from ALL applications
- Background recording without browser tab
- Desktop-level keyboard shortcuts
- Advanced screen capture settings

## Features
- ✨ System audio capture (all desktop apps)
- ✨ Background recording
- ✨ Global keyboard shortcuts
- ✨ Desktop app integration
- ✨ Advanced capture settings

## Development

```bash
cd chrome-extension
npm install
npm run build
```

Load the `dist/` folder as an unpacked extension in Chrome.

## Installation (End Users)
1. Visit Chrome Web Store
2. Click "Add to Chrome"
3. Grant permissions
4. Extension icon appears in toolbar

**Note:** Users can use the web app at https://yourapp.com without installing this extension!
