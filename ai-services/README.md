# AI/ML Services

Microservices for AI-powered features.

## Services
- `transcription/` - Whisper integration for audio-to-text
- `narration/` - ElevenLabs/Azure TTS for voice generation
- `step-detection/` - GPT-4 for automatic step identification
- `pii-detection/` - Computer vision for privacy protection

## Development

Each service can be developed and deployed independently.
